# MIRAI MIND
MIRAI MIND is an AI-powered cognitive diagnostics and predictive reasoning system built with Gemma models. It visualizes how different AI architectures evolve from reactive pattern recognition to adaptive behavioral analysis and deep systemic reasoning through futuristic dashboards, model reasoning matrices, and future drift simulations.

---

## Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/d6b1ea9f-1361-44c8-b606-92096f639e4f

### Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env` to your Gemini API key:
   ```bash
   GEMINI_API_KEY="your_api_key_here"
   ```
3. Run the app:
   ```bash
   npm run dev
   ```
